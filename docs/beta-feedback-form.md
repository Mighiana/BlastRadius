# Beta feedback — eleven questions

For invited beta testers after two or three real analyses. Short answers are
fine; skip anything you cannot share. There are no right answers and "it was not
useful" is as valuable as praise. Do not include real Terraform, resource names
or credentials.

Copy the block into an e-mail or GitHub issue reply, or answer it in a call.

```text
About your current process
 1. How do you review Terraform changes for security today? Describe the last one.
 2. Which tools or checks are involved in that review?

About the BlastRadius result
 3. Was the result understandable? What, if anything, did you have to re-read?
 4. Was it clear which change was responsible for the decision?
 5. Was the attack path useful? What would you have needed to verify it?
 6. Was anything incorrect or misleading?

About using it
 7. Would you run this on real pull requests? Under what conditions?
 8. What would prevent you from using it?
 9. Which missing capability matters most to you?

About buying it
10. Would you or your company consider paying for this? What would it need to do?
11. Who normally approves purchasing a tool like this in your organization?

Anything else:
```

For the owner: record answers verbatim with role, team size and the analysis IDs
discussed; separate quotes from interpretation. The longer
[discovery interview](customer-interview.md) is for a 45-minute conversation,
not for this form.
